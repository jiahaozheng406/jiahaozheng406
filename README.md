## 🚀 Research Philosophy

I am interested in building intelligent systems that connect **3D visual understanding**, **physical-world signals**, and **interactive generation**.

My work currently focuses on:

- 🧊 **3D Reconstruction & 3DGS**  
  Making sparse-view 3D representations more stable, geometric, and useful beyond pretty rendering.

- ⚛️ **AI for Quantum Sensing**  
  Learning from noisy physical signals, physics-guided constraints, and robust generalization in NV-center sensing.

- 🤖 **Robot Vision with Hardware Systems**  
  Connecting visual perception, real-time deployment, embedded hardware, and robotic decision-making.

- 🧩 **CAD / 3D Content Generation**  
  Exploring how AI can generate structured 3D assets, CAD-like representations, and editable visual worlds.

> Tiny belief: AI should not only describe the world.  
> It should also help us **reconstruct, simulate, edit, and interact with it**.
